# Продажа через Digiseller и вывод денег — шпаргалка

Кабинет продавца: https://my.digiseller.com (вход по почте dolchemilk2@gmail.com, ник karandax).
Админка Монтажки: https://dolchemilk2-blip.github.io/-228/montage/admin.html

## 1. Товар (один раз)
1. Админка Монтажки → «Продажа через магазин» → «Что даёт»: подписка на месяц (или навсегда) → выпустить 20–50 ссылок → скачается `.txt`
   (одна ссылка на строку). Сначала проверить одну ссылку со второго Google-аккаунта.
2. Digiseller → вверху «Товары» → «Добавить товар» → тип **«Уникальный товар с фиксированной ценой» → «уникальный текст»**.
3. Название, цена, валюта, категория («Программы»). Описание — готовое:
   > Монтажка — веб-приложение для сборки радиоспектаклей в браузере. После оплаты вы получите личную
   > ссылку: откройте её и войдите через Google — доступ включится сам на 30 дней. Купите снова — подписка
   > продлится ещё на месяц от её конца. Ссылка одноразовая.
4. В списке товаров у товара — «добавить» → загрузить `.txt` (разделитель — перевод строки).
   Один и тот же файл дважды не загружать.
5. Прислать Claude номер товара (ID) или ссылку на оплату — он поставит её на кнопку «Купить» (`buyUrl` в `montage/access/config.js`).
6. Когда ссылки кончаются — админка предупредит; выпустить новую пачку и снова «добавить».

## 2. Кошелёк и выплаты
Деньги падают на «личный счёт» Digiseller в WMZ (доллары WebMoney), комиссия площадки 1,5–6 %.
1. **WebMoney**: зарегистрироваться на web.money, создать **Z-кошелёк (WMZ)**.
2. **Формальный аттестат** (бесплатно): паспортные данные + скан удостоверения. Без него обменники не выводят.
3. **Digiseller → «Личный кабинет» → вкладка «Кошельки»** (рядом с «Контакты») → указать Z-кошелёк.
   Сделать скриншот этой вкладки и показать Claude — там видно, какие способы вывода доступны.
4. Спросить поддержку (в кабинете, блок «Мой магазин» → «задать вопрос»):
   «Как продавцу из Казахстана вывести деньги на карту?»
5. **Безопасность**: в кабинете включить защиту входа (вкладка «Безопасность»).

## 3. Как выводить в тенге (курс на 26.09.2026)
WMZ дешевле доллара: при выводе теряется ~23–28 %. Цену на Digiseller ставить с запасом ~25–30 %.
| Путь | Сколько за 1 WMZ |
|---|---|
| Официальный вывод WebMoney на карту («от 5 %») — проверить в кошельке: «Вывести» → «Банковская карта» | если доступен — лучший |
| WMZ → WMT (биржа WM Exchanger) → USDT через Гаранта WebMoney → Kaspi через обменник (bestchange.com) | ≈ 335–345 ₸ |
| WMZ → Kaspi напрямую через обменник (bestchange.com) | ≈ 320 ₸ |
| WM-Astana (wma.kz, через Halyk, по WhatsApp) | ≈ 315 ₸ |
Официальный курс доллара ≈ 443–448 ₸. Обменник выбирать с отзывами и резервом.
