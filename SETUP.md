# Как включить живой чат (Firebase)

Пока этот шаг не сделан, сайт полностью работает — но **каждый видит только свои
данные**: сообщения, письма и галочки хранятся в браузере и никуда не уходят.
В шапке при этом горит серая плашка «локальный режим».

После настройки вы окажетесь в **одной общей комнате**: чат, письма, настроение,
обнимашки и список желаний станут общими и будут обновляться в реальном времени.

Firebase бесплатен для такой нагрузки с огромным запасом — двум людям платного
тарифа не потребуется никогда.

---

## Шаг 1. Создать проект

1. Откройте <https://console.firebase.google.com> и войдите под Google-аккаунтом.
2. **Add project** → придумайте название (например `nash-sait`) → **Continue**.
3. Google Analytics можно смело выключить → **Create project**.

## Шаг 2. Включить базу данных

1. Слева в меню: **Build → Realtime Database** → **Create Database**.
   
   ⚠️ Важно: нужен именно **Realtime Database**, а не Firestore.
2. Регион — любой ближайший.
3. Выберите **Start in locked mode** → **Enable**.

## Шаг 3. Разрешить доступ

Откройте вкладку **Rules** внутри Realtime Database, замените всё содержимое
на это и нажмите **Publish**:

```json
{
  "rules": {
    "rooms": {
      "$room": {
        ".read": "auth != null",
        ".write": "auth != null"
      }
    }
  }
}
```

## Шаг 4. Включить анонимный вход

1. Слева: **Build → Authentication** → **Get started**.
2. Вкладка **Sign-in method** → в списке выберите **Anonymous** → включите → **Save**.

Это нужно, чтобы посторонние не могли писать в вашу базу напрямую.

## Шаг 5. Получить ключи

1. Шестерёнка вверху слева → **Project settings**.
2. Прокрутите до раздела **Your apps** → нажмите иконку **`</>`** (Web).
3. Придумайте название приложения → **Register app**.
4. Появится блок кода. Вам нужен объект `firebaseConfig` — примерно такой:

```js
const firebaseConfig = {
  apiKey: "AIzaSy...",
  authDomain: "nash-sait.firebaseapp.com",
  databaseURL: "https://nash-sait-default-rtdb.firebaseio.com",
  projectId: "nash-sait",
  appId: "1:123456789:web:abc123"
};
```

## Шаг 6. Вставить ключи в сайт

Откройте файл `assets/js/config.js` и перенесите значения в раздел `firebase`:

```js
  firebase: {
    apiKey:      "AIzaSy...",
    authDomain:  "nash-sait.firebaseapp.com",
    databaseURL: "https://nash-sait-default-rtdb.firebaseio.com",
    projectId:   "nash-sait",
    appId:       "1:123456789:web:abc123"
  },
  roomId: "pridumayte-svoyo-slovo",
```

`roomId` — секретное название вашей комнаты. Придумайте своё, латиницей и без
пробелов. Оно должно быть **одинаковым** у вас обоих (а оно и будет одинаковым,
раз файл один на весь сайт).

Сохраните файл, залейте изменения на GitHub — и через минуту в шапке загорится
зелёная плашка **«общая комната»**. Готово.

## Насколько это приватно

- Сайт по адресу GitHub Pages **виден всем, у кого есть ссылка** — но ссылку
  знаете только вы. Если хотите спрятать надёжнее, назовите репозиторий
  чем-нибудь неочевидным.
- Данные в базе защищены правилами из шага 3: писать и читать может только
  вошедший пользователь вашего Firebase-проекта.
- Это защита «от случайного прохожего», а не банковский уровень. Для переписки
  двух влюблённых — более чем достаточно. Пароли и номера карт сюда не пишите.
- **Письма-ссылки** (`🔗 Сделать ссылку`) в базу вообще не попадают: текст
  зашит прямо в адрес и живёт только в вашем мессенджере.

## Если что-то пошло не так

| Что видно | В чём дело |
|---|---|
| Плашка «локальный режим» после настройки | Проверьте, что заполнены `apiKey`, `databaseURL` и `projectId`, и что вы обновили страницу с очисткой кэша (Ctrl+Shift+R) |
| В консоли `PERMISSION_DENIED` | Не опубликованы правила из шага 3 |
| В консоли `auth/operation-not-allowed` | Не включён анонимный вход (шаг 4) |
| Сообщения не доходят второму | Разный `roomId` — убедитесь, что оба открываете один и тот же сайт |
