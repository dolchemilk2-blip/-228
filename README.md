# Монтажка

Редактор аудиоспектаклей и инструменты обработки звука.

- [`montage/`](montage/) — веб-приложение; запуск и сборка описаны в
  [montage/README.md](montage/README.md).
- [`pilot_audio/`](pilot_audio/) — Python-инструменты для сборки и очистки
  записей; инструкции — в [pilot_audio/README.md](pilot_audio/README.md).
- [Открыть Монтажку](https://dolchemilk2-blip.github.io/-228/montage/).

репозиторий [dolchemilk2-blip/kkk](https://github.com/dolchemilk2-blip/kkk).

нового сайта с сохранением параметров и фрагмента ссылки, в том числе
писем-ссылок. Настройки Firebase и идентификатор комнаты сохранены.
