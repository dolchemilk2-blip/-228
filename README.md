# Мы вдвоём 💜

Маленький сайт для двоих на расстоянии. Общий чат в реальном времени,
письма с запечатанной датой, счётчики, игры и наша история — всё на одной
странице, которую можно открыть с любого телефона.

**Живой адрес:** `https://dolchemilk2-blip.github.io/-228/`
(появится после шага «Публикация» ниже)

---

## Что внутри

| Страница | Что там |
|---|---|
| **Главная** — `index.html` | Посадочный талон до встречи (Алматы → Баку, самолётик стоит там, где вы сейчас на пути), время, погода и рассвет/закат в обоих городах с подсказкой, удобно ли сейчас звонить, кто на сайте и настроение, **вопрос дня** (ответ второго откроется, когда ответите оба) и кнопки «обнять / скучаю / спокойной ночи» |
| **Чат** — `chat.html` | Общая лента на двоих в стиле iMessage: ответы свайпом, реакции (долгое нажатие или двойной тап — ❤️), правка и удаление с кнопкой «Вернуть». На вкладке «Чат» горит цифра непрочитанных |
| **Письма** — `letters.html` | Конверты «авиапочта» в ваших цветах. Письмо можно положить на полку, **запечатать до даты** (даже автору не открыть раньше) или отправить ссылкой |
| **Игры** — `games.html` | Колода «Сто причин, почему ты», карточки-вопросы с переворотом, скретч-карточка и колесо свиданий |
| **История** — `memories.html` | Путь между городами, общая лента моментов (режим «Порядок» — переставлять), фото с телефона и список «когда встретимся» |
| **Сюрприз** — `quest.html` | Квест: поймать убегающий ключ, сломать печать, открыть конверт и прочитать признание |

### Как устроен дизайн

- **Сначала телефон.** Внизу — панель вкладок как в iOS, окна открываются
  шторкой снизу, её можно смахнуть пальцем. На компьютере — меню сверху
  и обычные окна.
- **Тема как у телефона:** днём светлая, вечером тёмная — сама.
- **Свой цвет у каждого:** у Димы фиолетовый, у Рагима синий. Кнопки
  и ваши сообщения окрашены в цвет того, кто держит телефон.
- **Шрифты системные** (SF Pro, SF Rounded, New York) и растут вместе
  с «Размером текста» в настройках iPhone.
- **Анимации** — короткие и упругие, в духе iOS; если в настройках включено
  «Уменьшение движения», сайт двигается заметно меньше.
- Удалили что-то по ошибке — внизу 5 секунд висит кнопка **«Вернуть»**.

## Как сделать его своим

Всё, что нужно менять, лежит в одном файле — **`assets/js/config.js`**.
Открывайте его прямо на GitHub (карандашик ✏️ в углу), правьте текст между
кавычками и сохраняйте. Через минуту сайт обновится.

Уже заполнено:

- Дима (Алматы, `Asia/Almaty`) и Рагим (Баку, `Asia/Baku`)
- Вместе с **9 июля 2026**, встреча **1 июня 2027** — годы проверьте
- 100 причин, 100 вопросов, 30 скретч-фраз, 12 идей для колеса

Осталось по желанию:

1. **Ключи Firebase** — чтобы чат стал общим (см. `SETUP.md`)
2. **Свои причины и вопросы** — дописывайте к готовым, чем личнее, тем лучше
3. **Таймлайн** — добавьте свои даты: первый созвон, первая встреча
4. **Фотографии** — добавляются прямо на странице «История», с телефона
5. **Тексты квеста** — включая финальное признание

Списки причин и вопросов длинные — не пугайтесь, просто дописывайте строки
в конец, перед закрывающей скобкой `],`.

## Публикация

Сайт статический — никакого сервера не нужно, GitHub раздаёт его бесплатно.

1. Откройте репозиторий на GitHub → **Settings** → **Pages**
2. В блоке **Build and deployment**:
   - Source: **Deploy from a branch**
   - Branch: **main**, папка **/ (root)**
3. **Save**

Через 1–2 минуты сайт будет доступен по адресу
`https://dolchemilk2-blip.github.io/-228/`. Отправьте ссылку второй половинке —
и добавьте её на телефоне на главный экран («Поделиться» → «На экран Домой»),
тогда сайт откроется как обычное приложение.

## Живой чат

Из коробки сайт работает **в локальном режиме**: всё сохраняется, но только
в вашем браузере — у второго человека будут свои данные. В шапке при этом
внизу главной написано «только этот телефон».

Чтобы чат, письма, настроение, обнимашки и галочки стали общими, нужно за
десять минут завести бесплатный Firebase. Пошаговая инструкция со скриншотами
шагов — в файле **[SETUP.md](SETUP.md)**. После настройки там будет
написано: **«вы оба видите одно и то же в реальном времени»**.

Письма-ссылки (кнопка «Ссылкой») работают всегда, даже без Firebase:
текст письма зашит прямо в адрес.

## Как это устроено

```
index.html      главная
chat.html       чат
letters.html    письма и капсулы
games.html      игры
memories.html   таймлайн, фото, список желаний
quest.html      квест с ключом
assets/
  css/style.css общие стили
  js/
    config.js   ← ВСЕ ВАШИ НАСТРОЙКИ И ТЕКСТЫ
    common.js   звёзды, «кто ты», время, уведомления
    cloud.js    синхронизация: Firebase или локальный режим
    home.js · chat.js · letters.js · games.js · memories.js
  img/          сюда фотографии
```

Ни сборки, ни зависимостей, ни npm — только HTML, CSS и обычный JavaScript.
Чтобы посмотреть локально, запустите в папке проекта:

```bash
python3 -m http.server 8000
```

и откройте <http://localhost:8000>. (Просто двойным кликом по `index.html`
не заработает: модули JavaScript требуют настоящего адреса `http://`.)

## Приватность

- Сайт открыт для всех, у кого есть ссылка, — но ссылку знаете только вы.
- Данные в Firebase закрыты правилами доступа (шаг 3 в `SETUP.md`).
- Это защита «от случайного прохожего», а не банковский уровень. Для двоих —
  более чем достаточно, но пароли и номера карт сюда писать не стоит.
