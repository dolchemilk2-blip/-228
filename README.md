# Мы вдвоём 💜

Маленький сайт для двоих на расстоянии. Общий чат в реальном времени,
письма с запечатанной датой, счётчики, игры и наша история — всё на одной
странице, которую можно открыть с любого телефона.

**Живой адрес:** `https://dolchemilk2-blip.github.io/-228/`
(появится после шага «Публикация» ниже)

---

## Что внутри

| Страница | Что там |
|---|---|
| **Главная** — `index.html` | Сколько дней вместе, обратный отсчёт до встречи, часы обоих городов с разницей поясов, кто сейчас на сайте, настроение дня и кнопки «обнять / скучаю / спокойной ночи» — они появляются у второго на весь экран |
| **Чат** — `chat.html` | Общая лента на двоих. Видно, когда второй печатает и когда был онлайн |
| **Письма** — `letters.html` | Письмо можно положить на общую полку или **запечатать до даты** — до неё его не открыть даже автору. А ещё превратить письмо в ссылку и отправить в мессенджер |
| **Игры** — `games.html` | «Сто причин, почему ты», карточки-вопросы для двоих, скретч-карточка «сотри и узнай» и колесо свиданий |
| **История** — `memories.html` | Мост между вашими городами, таймлайн важных дат, галерея фото и список «когда встретимся» с общими галочками |
| **Сюрприз** — `quest.html` | Квест: поймать убегающий ключ, открыть конверт, получить признание |

## Как сделать его своим

Всё, что нужно менять, лежит в одном файле — **`assets/js/config.js`**.
Открывайте его прямо на GitHub (карандашик ✏️ в углу), правьте текст между
кавычками и сохраняйте. Через минуту сайт обновится.

Что там настраивается:

1. **Имена, города и часовые пояса** — начните с этого
2. **Даты** — когда всё началось и когда встретитесь
3. **Ключи Firebase** — чтобы включить общий чат (см. `SETUP.md`)
4. **Причины, вопросы, идеи свиданий, скретч-сообщения** — тексты для игр
5. **Таймлайн, список желаний, фотографии**
6. **Тексты квеста** — включая финальное признание

Фотографии кладите в папку `assets/img/` и вписывайте их в раздел `photos`.

## Публикация

Сайт статический — никакого сервера не нужно, GitHub раздаёт его бесплатно.

1. Откройте репозиторий на GitHub → **Settings** → **Pages**
2. В блоке **Build and deployment**:
   - Source: **Deploy from a branch**
   - Branch: **main**, папка **/ (root)**
3. **Save**

Через 1–2 минуты сайт будет доступен по адресу
`https://dolchemilk2-blip.github.io/-228/`. Отправьте ссылку второй половинке —
и добавьте её на телефоне на главный экран («Поделиться» → «На экран Домой»),
тогда сайт откроется как обычное приложение.

## Живой чат

Из коробки сайт работает **в локальном режиме**: всё сохраняется, но только
в вашем браузере — у второго человека будут свои данные. В шапке при этом
серая плашка «локальный режим».

Чтобы чат, письма, настроение, обнимашки и галочки стали общими, нужно за
десять минут завести бесплатный Firebase. Пошаговая инструкция со скриншотами
шагов — в файле **[SETUP.md](SETUP.md)**. После настройки плашка станет
зелёной: **«общая комната»**.

Письма-ссылки (`🔗 Сделать ссылку`) работают всегда, даже без Firebase:
текст письма зашит прямо в адрес.

## Как это устроено

```
index.html      главная
chat.html       чат
letters.html    письма и капсулы
games.html      игры
memories.html   таймлайн, фото, список желаний
quest.html      квест с ключом
assets/
  css/style.css общие стили
  js/
    config.js   ← ВСЕ ВАШИ НАСТРОЙКИ И ТЕКСТЫ
    common.js   звёзды, «кто ты», время, уведомления
    cloud.js    синхронизация: Firebase или локальный режим
    home.js · chat.js · letters.js · games.js · memories.js
  img/          сюда фотографии
```

Ни сборки, ни зависимостей, ни npm — только HTML, CSS и обычный JavaScript.
Чтобы посмотреть локально, запустите в папке проекта:

```bash
python3 -m http.server 8000
```

и откройте <http://localhost:8000>. (Просто двойным кликом по `index.html`
не заработает: модули JavaScript требуют настоящего адреса `http://`.)

## Приватность

- Сайт открыт для всех, у кого есть ссылка, — но ссылку знаете только вы.
- Данные в Firebase закрыты правилами доступа (шаг 3 в `SETUP.md`).
- Это защита «от случайного прохожего», а не банковский уровень. Для двоих —
  более чем достаточно, но пароли и номера карт сюда писать не стоит.
