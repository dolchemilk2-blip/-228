# Аудиопилот — как пользоваться

1. Положи в папку `sources/` четыре файла (с такими же именами):
   `энер.wav`, `энер_правки_и_последняя_сцена.wav`, `кэфи.mp3`, `флур-enhanced-v2.wav`.
2. Открой эту папку в Claude Code и просто скажи, что нужно, например:
   «собери пилот», «вот запись организатора — вставь», «замени дубль Энер в 8 сцене».
   Всё про проект он прочитает в `CLAUDE.md`.
3. Готовое появится в `out/`: `пилот_сведение.mp3`, `пилот_паузы.txt`, `разметка.csv`,
   `громкость.txt`.

Дозаписанные реплики можно добавлять и самому: положи файл в `extra/`, назвав его номером
реплики из `пилот_паузы.txt` (например `extra/051.wav`), и пересобери.

## Чистка голоса (эхо комнаты, шум)

Отдельный шаг, делается один раз для каждой записи:

```
pip install "audio-separator[cpu]" clearvoice
python clean.py --sample 30      # чистит всё из sources/ → sources/чисто/
python build.py                  # сборка сама возьмёт очищенные файлы
```

`out/образец_до_после.mp3` — короткий кусок «как было / как стало», чтобы сравнить на слух.
Длительность записи при чистке не меняется, поэтому разметка реплик остаётся верной.
Подробности и что делать, если результат не нравится, — в `CLEAN.md`.

## Громкость

Сборка сама выравнивает голоса между собой и реплики внутри голоса, чтобы никто никого не
перекрикивал; шёпот остаётся шёпотом, а крик криком (ремарки «(шёпотом)», «(громко)» у имени
в сценарии учитываются). Что получилось — в `out/громкость.txt` и в колонках «уровень» и
«поправка» файла `out/разметка.csv`.

Поправить руками: в `extra/громкость.txt` дописать строку — `242 -3` (реплику 242 тише на 3 дБ)
или `Кэфи -1` (весь голос тише на 1 дБ). Плюс — громче, минус — тише.
Выравнивание целиком отключается: `python build.py --level 0`.

## Ручной запуск без Claude Code

Нужен Python 3 и ffmpeg, затем `pip install -r requirements.txt` и `python build.py`.
Полезные ключи: `--raw` (собрать из оригиналов, минуя `sources/чисто/`), `--wav` (сохранить
мастер без сжатия), `--mp3 192k`, `--level 0.3` (выравнивать слабее).
