# Аудиопилот — как пользоваться

1. Положи в папку `sources/` четыре файла (с такими же именами):
   `энер.wav`, `энер_правки_и_последняя_сцена.wav`, `кэфи.mp3`, `untitled.mp3`.
2. Открой эту папку в Claude Code и просто скажи, что нужно, например:
   «собери пилот», «вот запись организатора — вставь», «замени дубль Энер в 8 сцене».
   Всё про проект он прочитает в `CLAUDE.md`.
3. Готовое появится в `out/`: `пилот_сведение.mp3`, `пилот_паузы.txt`, `разметка.csv`.

Громкость реплик выравнивается сама — голоса к одному уровню, реплики внутри голоса к уровню
этого голоса; меняется только громкость, звук записей не трогается. Что получилось — в
`out/громкость.txt`. Если какая-то реплика всё равно не нравится, допиши строку в
`extra/громкость.txt`: `242 -3` — реплику 242 тише на 3 дБ, `Кэфи -1` — весь голос.
Слабее выравнивать: `python build.py --level 0.5`; выключить: `--level 0`.

Дозаписанные реплики можно добавлять и самому: положи файл в `extra/`, назвав его номером
реплики из `пилот_паузы.txt` (например `extra/051.wav`), и пересобери.

Чистка голоса (эхо, гулкость, «выбивается из остальных») — отдельный инструмент `clean.py`,
см. `CLEAN.md`. Он пишет в `sources/чисто/` и в сведение попадает только с `python build.py --clean`.

Ручной запуск без Claude Code: нужен Python 3 и ffmpeg, затем
`pip install -r requirements.txt` и `python build.py`.
